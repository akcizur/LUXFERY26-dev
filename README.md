# LUXFERY 26
Windows 98 style desktop runtime — React + TypeScript + Vite.

## Current foundation
- Win98 desktop, taskbar, Start menu, desktop shortcuts
- Window manager: focus, Z-order, move, minimize, maximize, Alt+F4, Ctrl+Esc
- Virtual C:\\ filesystem and Explorer
- Notepad, Calculator, Paint, Minesweeper, Control Panel
- GitHub Pages ready Vite configuration
- PWA manifest foundation

## Run
npm install
npm run dev
npm run build

## Roadmap
IndexedDB registry/session persistence, resize + context menus, Alt+Tab, modal dialogs, plugin API, sound engine, Solitaire, Winamp, IE/AIM modules.
